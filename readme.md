# Cheese Board

AI Powered chess engine. This code is still a WIP, but I'm submitting early for Summer of Making by HackClub. A Neural Network is trained on 100,000 snapshots from real LiChess games to try and predict the winner. This neural network is then used in a game tree crawler for the engine to traverse all possible paths (up to a specified depth) and evaluate it on how likely a position results in a win for the bot. It then plays moves accordingly
